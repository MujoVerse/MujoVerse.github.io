---
title: 驾驶机甲（MinePilot）
description: "坐进机器人的驾驶位，用键盘鼠标开它。"
---

装上 MinePilot 之后，任何一台 T2 或 G1 都是你的机甲：坐进去，用平时走路的按键开它。它的每一步都是真的迈腿，地形不平会晃，被撞会摔。

## 上机与下机

- 走近机器人，**空手右键**它，或看着它按 **F**，或执行 `/minepilot drive`。
- 按 **G** 或执行 `/minepilot leave` 退出。
- 同一时间一台机器人只能被一个驾驶者控制。

## 操作

| 按键 | 作用 |
|---|---|
| WASD | 行走；普通 1.5 m/s，后退和横移有各自的上限 |
| 疾跑 | 前进最快 3 m/s（T2） |
| 潜行 | 精细移动 0.5 m/s |
| 鼠标 | 先转头，超过颈部极限后身体跟着转 |
| F5 | 第一人称 / 第三人称切换 |
| 左键地面 | **点选导航**：机器人走到准星指向的位置 |
| `=` / `-` | 调节下一次任务的速度 |
| **H** | 摔倒后请求起身 |

所有按键都可以在「选项 → 控制 → 按键绑定 → MinePilot」里修改。

HUD 会显示控制模式、请求速度和实际速度、姿态、目标距离。机器人没有的能力会显示为「不可用」，例如 G1 没有头部控制。
