---
title: 物理工具（MujoCraft）
description: "让方块建筑真的会倒，再用重锤敲它。"
---

MujoCraft 给 Minecraft 装上了真实的物理引擎。除了让机器人走路，它还能把任何方块建筑变成**刚体**：一整块有重量、会被推动、会翻倒的结构。

## 刚体装配杖

| 操作 | 作用 |
|---|---|
| 左键方块 | 选定角点 A |
| 右键方块 | 选定角点 B（会显示选区轮廓和方块数） |
| 潜行 + 右键 | 把选区里的方块变成一个刚体 |

刚体的质量按方块体积计算（每格约 700 kg），它会受重力、与地形和其他刚体碰撞、被机器人推动。生存模式下选区最多 512 格，不能装配基岩等无法破坏的方块。

合成：紫水晶碎片 + 两个铜锭，斜向摆放。

## 物理重锤

| 操作 | 作用 |
|---|---|
| 左键敲击刚体或机器人 | 从敲中的位置推它一下；敲偏了会让它打转、翻倒 |
| 蓄满力再敲 | 力度最大 |
| 潜行敲击 | 轻敲 |
| 右键 / 潜行 + 右键 | 加大 / 减小力度（×0.25 到 ×4，五档） |

重的东西被推得更少：一锤能让机器人踉跄，房子只会晃一下。

合成：上排三个铁块，中间一铁块一木棍一铁块，下排中间一根木棍。

## 命令

| 命令 | 作用 |
|---|---|
| `/mujocraft assemble <起点> <终点>` | 把区域内的方块变成刚体 |
| `/mujocraft impulse <x> <y> <z>` | 推一下最近的刚体（数值越大推得越狠） |
| `/mujocraft list` | 列出刚体 |
| `/mujocraft demo` | 在身边生成一个演示刚体 |

## 瓦尔基里天空（Valkyrien Skies 2）

MujoCraft 另有一个 Minecraft 1.20.1 的适配模块，让我们的刚体与 VS2 船体相互碰撞、相互推动：转台能把方块甩出去，箱子能把雪橇撞走，重锤能敲动船。它是独立的实验版本，不和 1.21.1 的模组装在一起。
