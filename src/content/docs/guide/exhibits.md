title: 机器人图鉴
description: "33 款机器人展品、展台和信息卡。"
---

图鉴里有 33 款来自公开模型的机器人：人形、四足、双足、机械臂、灵巧手、移动操作机器人和无人机。每一款都随附原始许可证。

## 放置展品

打开创造物品栏的 **MujoBots** 标签页，每款机器人是一个**机器人胶囊**（实时机器人在前，展品按类别排在后面）。拿着胶囊右键地面，机器人就会站在那里，面朝你。

| 操作 | 作用 |
|---|---|
| 右键展品 | 切换动作（姿态、舞蹈、关节演示等） |
| 潜行 + 右键 | 暂停 / 继续 |
| 看向展品 | 右上角显示信息卡：名称、厂商、年份、关节数、身高、模型许可 |
| 创造模式左键 | 移除展品 |

展品只播放预先计算好的动作，不做物理，所以放上几十台也几乎不影响性能。

## 机器人展台

**机器人展台**是一个可以在生存模式合成的方块：三个平滑石台阶 / 铁锭、红石、铁锭 / 三个磨制深板岩，一次得到 2 个。

给展台一个红石信号（按钮、拉杆、压力板都可以），站在所有**相连**展台上的机器人会一起从头播放。用它可以让并排的几台机器人同步表演。

## 命令

| 命令 | 作用 |
|---|---|
| `/mujobots robots [类别]` | 列出全部机器人（可点击生成） |
| `/mujobots spawn <机器人> [x y z] [朝向]` | 生成一台 |
| `/mujobots exhibit gallery [类别]` | 一次摆出全部（或某一类） |
| `/mujobots exhibit play\|pause\|restart\|next\|remove [目标]` | 控制最近的展品，或选择器选中的展品 |
| `/mujobots exhibit speed <倍速> [目标]` | 调整播放速度 |
| `/mujobots exhibit clip <动作> <目标>` | 指定动作 |

`[目标]` 支持实体选择器，例如 `@e[type=mujobots:exhibit,distance=..8]`，可以用在命令方块里。
