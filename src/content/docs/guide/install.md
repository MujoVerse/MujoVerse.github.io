## 你需要什么

| 项目 | 要求 |
|---|---|
| Minecraft | Java 版 **1.21.1** |
| 加载器 | **Fabric Loader 0.16.10** 或更新 |
| 前置 | **Fabric API**（1.21.1 版本） |
| 系统 | Windows x64、Linux x64、macOS（Apple 芯片） |
| 内存 | 建议给游戏分配 **4 GB** 以上 |

不需要另外安装任何东西：物理引擎和机器人的“大脑”都已经打包在模组里。

:::caution[Windows 用户]
G1、K1、T1、Go1 用到的神经网络运行库需要「Microsoft Visual C++ 2015–2022 可再发行组件 (x64)」，大多数电脑已经装过。如果缺少，生成这些机器人时游戏会提示你，不会崩溃；其他功能不受影响。
:::

## 方式一：只装模组

1. 用你常用的启动器（官方启动器、Modrinth App、Prism、PCL、HMCL 等）创建 Fabric 1.21.1 实例。
2. 把下列 jar 放进实例的 `mods` 文件夹：

| 模组 | 作用 | 必需？ |
|---|---|---|
| MujoCraft | 物理引擎 | 必需 |
| MujoBots | 机器人核心 | 必需（依赖 MujoCraft） |
| 机器人包：T2、G1、K1、T1、Go1、展品 | 每个包一台机器人或一组展品，按需安装 | 至少装一个 |
| MujoBots ONNX Runtime | 神经网络运行库 | G1、K1、T1、Go1 需要 |
| MinePilot | 驾驶机器人，程序与 AI 接口 | 推荐 |
| MineArena | 机器人足球 | 可选（依赖 MujoBots） |
| Fabric API | 前置 | 必需 |

3. 启动游戏，新建一个**创造模式**世界，打开创造物品栏里的 **MujoBots** 标签页和「工具与实用物品」。

## 方式二：博物馆整合包

想先看看能做什么，就下载[博物馆桌面试玩](/guide/museum/)。把 `.mrpack` 导入为新实例即可获得存档和匹配的模组；已有配套模组的实例可以只下载存档 ZIP。

## 常见问题

- **机器人生成后不走？** 它默认原地站立。手持 T2 行走遥控器右键它，或用 [MinePilot](/guide/driving/) 坐进驾驶位亲自开。
- **画面卡？** 每台实时机器人都在不停地计算物理和动作，数量多了会占用 CPU。展品机器人（图鉴里的）不做物理，几乎不占性能。
